1. Problem

Financial reports mix tables and text. A question like “What was revenue growth?” needs four skills: locate the row, extract values with unit/scale/sign (₹ crore; “(6,537)” = −6,537), choose the formula, and compute without slips. LLMs are fluent but unreliable at this.

2. Objectives

  1. Compare 7 prompting strategies: direct, zero/few-shot CoT, decomposition, Program-of-Thought, Self-Consistency and our VPSC.
  2. Test automatic optimization: DSPy BootstrapFewShot, MIPROv2, TextGrad — vs hand-written prompts, with their cost.
  3. Compare Qwen3-1.7B and Qwen3-8B (local, Ollama) on accuracy, tokens, latency.
  4. Analyse errors and robustness; test on 44 new questions from Indian annual reports.

5. Approach in one sentence

Load question → build context (table as Markdown, optional retrieval) → prompt with a strategy → run code in a sandbox → score (0.5% tolerance) → classify errors → statistics. Only the strategy changes between runs.

6. Likely questions

What is the project in one line?
We test which prompting and prompt-optimization methods make LLMs accurate and cheap at numerical questions over financial reports, using local models.
Why not fine-tune?
Needs labelled data, GPUs and retraining for every model; prompting is cheap, works with any model and is the course focus.
Why Program-of-Thought?
LLMs make arithmetic slips; in PoT the model writes Python and the computer calculates exactly.
What is new?
A fair manual-vs-automatic prompting comparison with cost and significance; a training-free grounding check inside program voting (VPSC); and Indian multi-step calculation questions.
Isn't this already done (VeriFin, IndFin-Bench)?
Related, not the same: VeriFin needs XBRL data and a solver, DCRC needs training — VPSC needs neither. IndFin-Bench is mostly fact look-up; our Indian set is multi-step calculation.
Why local models?
Financial data is sensitive; local models keep data on the laptop and cost nothing per query.
Why an Indian set?
The main benchmarks are US filings; Indian reports use ₹ crore/lakh, 1,00,000 grouping and bracketed negatives, and existing Indian benchmarks do not test multi-step calculation.
