Grounding check: every number in the code must appear in the report. The ablation (PoT-SC) uses the same 5 programs without the check.

Scoring

Scoring rule

  • Correct if within 0.5% of the gold answer (or equal at the gold's precision)
  • Percentages: 12.5 and 0.125 both accepted (FinQA stores fractions, TAT-QA percents)
  • Parser handles ₹, $, 1,00,000 grouping, (brackets) = negative, crore / lakh / million
  • Statistics: 95% bootstrap CI; paired McNemar test vs few-shot CoT (Holm-corrected)
One scorer everywhere: experiments, DSPy metric, TextGrad, the app and the analysis.

Safety

Sandbox: running model code safely

  • Static check: only import math; no files, network or dunders
  • Separate isolated Python process for each program
  • Safe builtins only; CPU limit + 5 s timeout
Model-written code is untrusted — four independent layers keep it harmless.
